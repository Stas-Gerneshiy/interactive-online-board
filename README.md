# Вебресурс «Інтерактивна онлайн-дошка для колективної роботи»

## Опис проєкту

Вебресурс «Інтерактивна онлайн-дошка для колективної роботи» — це вебзастосунок для створення, редагування та спільного використання інтерактивних онлайн-дошок. Система дозволяє користувачам працювати з нотатками, геометричними фігурами та лініями, змінювати їх розмір, колір і положення, а також синхронізувати зміни між кількома користувачами в режимі реального часу.

Проєкт розроблений як клієнт-серверний вебресурс із використанням REST API, PostgreSQL та Socket.IO.

## Основні можливості

- реєстрація та вхід за email і паролем;
- авторизація через Google OAuth 2.0;
- JWT-захист API-запитів;
- створення, перейменування та видалення онлайн-дошок;
- додавання інтерактивних нотаток із текстом;
- додавання прямокутників;
- додавання ліній;
- зміна кольору елементів;
- зміна розміру нотаток і прямокутників;
- зміна довжини та поворот ліній;
- масштабування дошки колесиком миші відносно курсору;
- переміщення полотна дошки;
- обмеження мінімального розміру нотатки відповідно до тексту;
- перенесення слів у нотатках цілими словами;
- блокування перетягування нотатки під час редагування тексту;
- синхронізація змін між користувачами через Socket.IO;
- генерація посилань спільного доступу;
- режим доступу «тільки перегляд»;
- режим доступу «редагування»;
- панель адміністратора;
- перегляд списку користувачів;
- блокування та розблокування користувачів;
- видалення користувачів;
- перегляд і модерація створених дошок;
- статистика кількості користувачів і дошок.
